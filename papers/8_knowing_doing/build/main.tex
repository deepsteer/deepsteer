\begin{abstract}
A model can state that an action is wrong and take it anyway. We measure that gap scenario by
scenario on an open 7B model, with the model's own stated judgment as the reference and a
discrete, logged action as the outcome, so that no external ethics enters the measurement. The
panel is pre-registered: 248 scenarios across five pressure families (task completion, sycophancy
under pushback, prohibited shortcuts, in-group favor, third-party harm), each written in a matched
agent frame and a third-person judgment frame, each with a pressure-removed twin and three
paraphrased judgment frames, half written by each of two generator models and cross-labeled by
the other.

On OLMo-3-7B-Instruct the model takes the action it judged wrong on one screened scenario in
five by majority vote (0.19, 95\% CI 0.13 to 0.28) and on two rollouts in five. Every number
sits inside a calibration ladder: the gap exceeds the same statistic on pressure-removed twins by
0.10 (0.02 to 0.18), and a known-gap control in which the system prompt orders the violating
action reaches 0.58. A noisy judgment reference could manufacture such a gap, so the reference
is elicited on four frames and the gap is read at three strictness levels. On a pre-registered
log-probability readout the excess over the null holds at every level and is largest at the
strictest, where all four frames agree (0.08, 0.03 to 0.13); on the majority readout it is not
resolved there at 43 pairs, which is the majority rule losing information, not the gap shrinking.
The gap has no family structure at this power: third-party harm is not the family where it is
smallest, so the action channel is not organized by the harm content that refusal reads.

The base model already carries the gap. In a raw completion frame its acting-versus-judging mass
gap exceeds its own pressure-removed null (0.017, 0.012 to 0.022), and post-training does not
remove that pressure-attributable part: on the same scenarios it enlarges it (0.046, 0.025 to
0.069), on the acting side, while lowering the model's baseline willingness to take the violating
action. We release the panel, the harness, the pre-registration with its seventeen dated
amendments, and the per-scenario arrays.
\end{abstract}
