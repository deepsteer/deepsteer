# Shared rsync excludes for all DeepSteer RunPod syncs (rsync --exclude-from).
#
# These are the UNIVERSAL "never ship over the wire" patterns. They are applied
# FIRST (highest precedence), so a per-paper output include cannot accidentally
# re-add a model blob.
#
# Each launcher appends, AFTER this file, two filters to keep only its OWN
# paper's outputs:
#     --include '/papers/<self_paper>/outputs/***'
#     --exclude '/papers/*/outputs/'
# Result: the deepsteer package + the launching paper's outputs (small
# directions .npz / results .json) sync; every other paper's outputs and all
# large blobs are skipped.
