\begin{abstract}
A causal claim about what a model's circuit reads or writes is only as
good as the instrument that measured it, and interpretability
instruments fail in specific, diagnosable ways. A covariance-matched
null can saturate so every direction projects like a typical one; a
per-head attribution can overshoot the true residual write threefold;
an interchange patch can go sign-chaotic because its outcome is pinned
at a ceiling; a reads-X verdict can be an artifact of measuring past
the layer where the model already decided. This methods note collects
six such failures from a causal interpretability program on refusal
and moral representation across four language-model architectures.
Each first looked like a finding. We state each as a protocol others
can run: calibrate the instrument against a positive-control ladder,
certify it with an orthogonal cell, compute power before spending
compute, and state every read-from verdict at a depth referenced to
the model's commitment. Every scalar carries its detection bar or its
control.
\end{abstract}
